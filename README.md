# 🌸 Iris AI Predictor

## 📌 Overview
This project predicts Iris flower species using Machine Learning algorithms through an interactive Streamlit web application.

## 🤖 Models Used
- Logistic Regression
- KNN
- Decision Tree
- SVM

## 🛠 Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## 🌸 Features
- Interactive UI
- Model selection
- Confidence prediction
- Probability visualization

## 📊 Dataset
Iris Dataset from Scikit-learn.

## 🚀 Output
The system predicts:
- Setosa
- Versicolor
- Virginica
